# Data Cleaning & Reporting Automation

## Project Overview

This project focuses on automating the cleaning, validation, analysis, and reporting of customer support ticket data.

Customer support datasets may contain missing values, duplicate records, inconsistent formats, and invalid data. Manually cleaning and preparing such data for reporting can be time-consuming and error-prone.

This project develops an automated data analytics workflow using Python, Excel, and Power BI to transform raw customer support data into clean, validated, analysis-ready information and interactive reports.

---

## Objectives

- Automate the cleaning and preprocessing of customer support ticket data.
- Identify missing values and duplicate records.
- Detect invalid values and inconsistent data formats.
- Validate the quality of the dataset before analysis.
- Generate meaningful KPIs and analytical summaries.
- Create visualizations for customer support analysis.
- Automate the generation of an Excel report.
- Develop an interactive one-page Power BI dashboard.
- Improve reporting efficiency and consistency.

---

## Dataset

**Dataset:** Customer Support Ticket Dataset

**Source:** Kaggle

The dataset contains customer support ticket information including:

- Ticket ID
- Customer Name
- Customer Email
- Customer Age
- Customer Gender
- Product Purchased
- Date of Purchase
- Ticket Type
- Ticket Subject
- Ticket Description
- Ticket Status
- Resolution
- Ticket Priority
- Ticket Channel
- First Response Time
- Time to Resolution
- Customer Satisfaction Rating

### Dataset Size

- **Rows:** 8,469
- **Columns:** 17
